Поиск аномальной активности респондентов по брендам
Описание алгоритма
Аномалией считается чрезмерно высокая дневная активность респондента по конкретному бренду в рамках категории `CategoryNameDelivery`.
Метод: максимальный разрыв (gap detection) в отсортированных значениях `daily_ots`.

Для каждой группы `(CategoryNameDelivery, BrandID, researchdate)`:
1. Сортируем все ненулевые `daily_ots` респондентов.
2. Находим максимальную разность между соседними значениями.
3. Порог = последнее значение перед этим разрывом.
4. Аномальными считаются респонденты с `daily_ots > порог`.

Почему именно так сделать надо?:
- Порог полностью вычисляется из данных, без ручных коэффициентов.
- Метод не требует предположений о распределении.
- Детерминирован и интерпретируем.
- Единственный параметр `MIN_RESPONDENTS_PER_GROUP = 20` – защита от малых выборок (не влияет на порог).

Агрегация OTS:  
`daily_ots = max(Weight) * количество запросов` для каждой пары `(SubjectID, researchdate, BrandID, CategoryNameDelivery)`.
Удаление:  
Если респондент аномален хотя бы по одному бренду в день, удаляются **все** его строки за этот день.
